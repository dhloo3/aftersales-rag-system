# AX-200 工业空压机用户手册（演示样例）

文档类型：用户手册  
适用型号：AX-200  
版本：演示版 V1.0  
资料性质：虚构样例，仅用于软件演示。

## 日常巡检

每次开机前检查设备周围是否有遮挡，确认散热通道畅通。运行期间观察控制面板的温度和压力读数，发现异常声音或异常气味时停机并联系售后工程师。

## 滤芯维护

每 500 运行小时检查一次进气滤芯。若滤芯明显积尘，应按现场维护规范清洁或更换，并记录设备编号、运行小时数和处理日期。不得在设备运行或未断电时拆卸滤芯。

## 资料使用范围

本手册只适用于 AX-200。其他型号即使告警码相同，也应先查对应型号的资料。
