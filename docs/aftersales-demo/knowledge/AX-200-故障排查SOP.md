# AX-200 故障排查 SOP（演示样例）

文档类型：故障排查 SOP  
适用型号：AX-200  
版本：演示版 V1.0  
资料性质：虚构样例，仅用于软件演示。

## E17：排气温度过高

现象：控制面板显示 E17，设备可能自动停机。

处理顺序：

1. 停机并切断电源，等待设备冷却；现场人员遵守本单位的上锁挂牌流程。
2. 检查设备周围的散热空间及散热通道是否堵塞，记录控制面板温度读数。
3. 检查进气滤芯维护记录；若已到 500 运行小时检查周期，按用户手册执行检查。
4. 清理可见的外部遮挡后，由有资质人员按现场规范复核。若 E17 再次出现，停止使用并升级给售后工程师，不在本 SOP 中直接给出内部部件更换结论。

## 未收录告警码

遇到本 SOP 未收录的告警码时，记录型号、设备编号、告警码及发生时间，联系售后工程师核对正式资料，不推断维修步骤。
